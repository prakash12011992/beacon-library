
BEACON LIBRARY WEBSITE

How to Publish Free:

1. Go to https://github.com
2. Create a free account.
3. Click "New Repository".
4. Name it: beacon-library
5. Upload these 3 files:
   - index.html
   - style.css
   - script.js

6. Go to Settings → Pages.
7. Select branch: main → Save.

Your website will be live at:

https://yourusername.github.io/beacon-library

Students can open that link and see seat availability.
